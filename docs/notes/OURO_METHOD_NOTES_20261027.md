# Ouro 训练方法摘录与我们的适配（arXiv:2510.25741）

> 来源：Zhu et al., *Scaling Latent Reasoning via Looped Language Models*,
> arXiv:2510.25741（v6, 2026-10-11）。字节跳动，Ouro 1.4B / 2.6B，7.7T token。
> 摘录时间 2026-10-27，用于对照本项目的 LDM 训练配方。

---

## 1. Ouro 的三根支柱

1. **隐空间迭代计算**：共享权重栈反复作用于隐状态，不生成 token。
2. **熵正则目标，学习深度分配**：训练退出分布，而非固定轮数。
3. **大规模预训练**：7.7T token。

## 2. 训练流程（两阶段）

### 第一阶段：联合训练 + 熵正则

- 每次递归都输出 (a) 语言模型预测，(b) 退出概率 q_t。
- 损失 = **各步 next-token loss 按退出分布加权** + **熵项**。
- 关键：**均匀先验（uniform prior）**，鼓励探索所有深度，
  防止模型塌到单一轮数。
- 轮数 T 从任务特定区间随机采样（如 T ~ U(1,12)），起到正则作用，
  使模型在不同计算深度上都产出稳定输出。

### 第二阶段：冻结主体，只训 gate

- **冻结语言模型**，只训练退出 gate。
- gate 学："再循环一轮能否可测量地降低 token loss"。
  能降 → 继续；停滞 → 退出。
- 推理时用**累积概率阈值**决定停止。

## 3. 关键实验证据（合成任务）

### Mano（树结构模运算组合）

| 配置 | 准确率 |
|---|---|
| 2 层，跑 1 次 | 7.5% |
| **2 层，循环 6 次** | **78.0%** |
| 12 层，跑 1 次（等效深度、同 FLOPs） | 34.8% |

**循环 > 等效深度稠密**，这是 Ouro 最强的机制证据。

### Capo（合成传记记忆）与多跳 QA

- **存储容量**：looped 与非 looped 都是约 2 bits/参数 → 循环**不增加**存储。
- **多跳合成 QA**：循环次数越多，达到高精度所需的**唯一训练样本越少**（样本效率）。

### 论文自己的定位

> "优势不来自知识容量，而来自更强的知识操作能力。"

## 4. 与我们 LDM 的逐项对照

| 维度 | LDM（我们） | Ouro |
|---|---|---|
| 参数 | 1.47M | 1.4B / 2.6B |
| 训练 token | 合成任务流式生成，24k 步 | 7.7T |
| 轮数监督 | persist-sup（第 R 轮起每轮都要对）+ step-sup | 退出分布加权 CE |
| 轮数采样 | **固定 R = hop−1** | **随机 T ~ U(1,12)** |
| 深度先验 | 几何 `(1−λ)λ^t`（PonderNet，鼓励早停） | **均匀先验 + 熵奖励** |
| 退出控制 | 可选 PonderNet（单阶段） | **两阶段，第二阶段冻结主体只训 gate** |
| 任务 | MVT（符号图路径追踪） | 真实文本 + 合成诊断任务 |

## 5. 我们已实现的适配

`s71_ldm_iter4.py` 新增 `--ouro` 分支（`ouro_loss`）：

```python
# 与 ponder_loss 的两点差异：
#   ① 均匀先验（非几何）：KL(p || U) = logT - H(p)
#   ② 额外熵奖励 -β·H(p)
loss = Σ_t p_t·CE_t + beta_ent * (log T - H(p))
```
可选 `--step-sup` 叠加路径监督；`--beta-ent` 默认 0.05。

**实验**：`OURO_{a,b}_s{17,71}`（4 run，24k 步，MVT-D v2）。

## 6. 预期与判据（预注册）

**动机**：MVT-D v2 上 s71 在 r=2 就饱和（0.868），r=3–8 无增益。
几何先验会**主动鼓励**这种早停；Ouro 的均匀先验 + 熵奖励应把分布推开。

**判据**：
- **Ouro 有效**：r=3–8 相对 r=2 有 >3pp 增益，且 `e_halt` 明显上升；
- **无差异**：r 扫描仍平坦 → 说明任务本身只需两阶段（与损失无关），
  此时"循环承载串行深度"在本任务上不可检验，应改任务而非改损失。

## 8. 实测观测（2026-10-27 16:30，MVT-D v2，4k 步）

`OURO_{a,b}_s{17,71}`（同 seed 双跑验证确定性）：

| seed | loss | 熵 H(p) | e_halt | q_1 | q_last |
|---|---|---|---|---|---|
| s71 | 1.412 | **2.079** | 4.51 | 0.872 | 0.650 |
| s17 | 1.655 | **2.079** | 4.54 | 0.872 | 0.624 |

**关键**：熵稳定在 **2.079 = ln 8**（T=8 时的理论最大值），
说明退出分布被推成**接近均匀**，8 轮全部参与计算，没有塌到某几轮。
`e_halt ≈ 4.5`（8 轮的中段），q_1=0.87（第一轮就停的概率仅 13%）。

这与 persist-sup 的固定 R=hop−1 形成对比：
persist 只在前 R 轮之后施加监督，模型没有"使用更多轮"的动机；
Ouro 的均匀先验 + 熵奖励强制所有轮都被用到。

**待观察**：loss 从 1.84 → 1.41（4k），是否继续下降；
以及最终 r 扫描是否出现 r=3–8 相对 r=2 的增益。
