## 三、关键机制：48k 的收益来自"覆盖 hop6"，不是"练得更久"

- **24k run**：训练课程只到 cap=4（16000–24000 步），hop5 仅在最后一步引入。
  → **hop6 从未训练**。
- **48k run**：cap=6 从 32000 步开始，**hop6 训练了 16000 步**。

结果：
| | h6 | h7 |
|---|---|---|
| 24k（未训 hop6） | 0.645–0.695 | 0.620–0.655 |
| 48k（训了 hop6） | 0.720–0.900 | 0.695–0.915 |

**h7 的提升来自 h6 被训练，而不是步数本身。**
这与 H-014/H-022 的结论一致：**只有训练覆盖有效**。

## 四、最干净的深度外推证据（24k run）

24k run 训练只覆盖 hop2–4，但评测结果：

| 深度 | 训练？ | 准确率 |
|---|---|---|
| hop4 | 是 | 0.795–0.830 |
| hop5 | 几乎未训 | 0.700–0.795 |
| hop6 | 未训 | 0.645–0.695 |
| hop7 | 未训 | 0.620–0.655 |
| hop8 | 未训 | 0.600–0.620 |

**从训练深度 4 外推到 8（4 跳），准确率从 0.80 降到 0.61，全程远高于随机（0.5）。**

这是目前最可信的深度外推证据：
- 任务无捷径（MVT-D v2）
- 训练深度有日志可查（cap=4）
- 外推跨 4 跳
- 不依赖"未训练轮数"（训练中 r=1..8 全部用过）

## 五、与 Kohli 2026 的明确冲突

Kohli（arXiv:2604.07822）："深度外推需推理轮数 ≥ 深度"。
我们的 hop7 在 **r ≤ 8** 下达到 0.655（未训 h6）到 0.915（训了 h6），
hop8 达到 0.600–0.880。

**模型用远少于跳数的轮数完成外推** → 压缩式推理。
可能原因：本任务无邻接掩码，一轮可传播多跳；
Kohli/Chen 的任务有拓扑掩码，强制每轮一跳。

## 八、邻接掩码诊断（P1-2 前置，22:30）

### 做法
用 `s88_adj_task.py` 构造事实级邻接（fact i 的 obj == fact j 的 subj 即一跳边），
第 t 轮只允许事实位置看到 ≤ t 跳内的事实；候选/标记位置不受限。
对训练好的 `P04_cs48k_s71`（无掩码，h6=0.900）在推理时施加掩码。

### 结果

| r | h2 | h3 | h4 | h5 | h6 |
|---|---|---|---|---|---|
| 无掩码 r=8 | 0.99 | 1.00 | 0.92 | 0.90 | 0.90 |
| **加掩码 r=8** | 0.80 | **0.55** | 0.67 | 0.64 | **0.67** |

### 解读（谨慎）

**提示性**：模型依赖跨多跳的直接注意力，而非逐跳状态传播。
加掩码后 h3–h6 从 0.90 掉到 0.55–0.68。

**但这不是证明**：模型是**无掩码训练**的，推理时施加新的注意力约束，
任何模型都会掉分。要证明"压缩式推理"，必须**用掩码训练**，
看它能否学会、以及阶梯是否随 h 出现。
