## 关键判读

1. **MVT-5 上的所有"能力"结论作废**（H-001/H-003/H-011/H-013/H-014/H-022）。
2. **无捷径任务上，循环提供的是"两阶段精修"而非"每轮一跳"**：
   s71 所有 hop 在 r=2 同步跳变，转折点不随 hop 平移。
3. **但出现了真实的深度外推**：hop7/8 未训练却达 0.83/0.785。
4. **seed 方差大**（1/3 成功），是当前主要障碍。
