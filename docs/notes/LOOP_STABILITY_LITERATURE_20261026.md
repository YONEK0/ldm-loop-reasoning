# 循环模型训练不稳定的文献结论与对策（LDM 线，2026-10-26）

**触发问题**：§19.9 多 seed 验证中 4 个 seed 只有 2 个解出全部难度（hop5/6），
失败率 50%。失败模式是**优化轨迹发散**（seed53 从 8k 的 0.68 单调震荡下滑到 0.49，
加大预算到 32k 反而更差），不是容量不足。查文献找标准解法。

---

## 1. 最对口的文献：Fully Looped Transformer（arXiv:2605.18797v2）

Rao Fu et al., "Simply Stabilizing the Loop via Fully Looped Transformer", 2026-05.

### 1.1 他们诊断出的两类不稳定（我们全部命中）

| 现象 | 描述 | 我们的对应证据 |
|---|---|---|
| **Gradient oscillation** | 训练早期梯度 L2 范数剧烈震荡；loop 数越多越严重。归因于共享权重导致梯度沿 loop 维累积（类似 BPTT） | seed53 的 r8 轨迹 0.68→0.49 震荡下滑；seed41 的 r8 从 0.916 掉到 0.786 |
| **Residual explosion** | 残差状态范数随 loop 迭代快速膨胀；即使每层都有 RMSNorm 仍发生。归因于有效循环深度导致残差在循环维度累积放大 | **我们从未测量过这个量**——这是诊断缺口 |

### 1.2 关键量化事实（可直接引用）

- 原版 LT 在 **base 规模（318M）9 loop 就崩**（表中标 "-"）；6→9 loop 时 PPL 从 51.38 恶化到不可用。
- small 规模（127M）不崩但单调退化：3/6/9 loop 的下游均值 32.57/31.47/30.22。
- **他们的修复（FLT）能稳定训练到 12 loop**，base 规模 9 loop 时下游均值 41.72（原版 3 loop 才 40.52）。
- 我们的模型 1.4M 参数、8 loop，处在他们验证过的稳定区间内——**所以我们的失败不是"loop 太多"**，而是别的因素（见 §3）。

### 1.3 他们的两个修复（参数零增加）

1. **Fully Looped Architecture (FLA)**：上一轮循环的输出不只喂给下一轮的第 1 层，
   而是喂给下一轮的**每一层**。缓解残差爆炸。
2. **Attention Injection (AI)**：不是把上一轮 h 直接加进残差流，而是把上一轮 h 当作
   **Query**、当前层表示当 K/V 做 cross-attention。softmax 归一化天然限制注入信号幅度，
   抑制梯度震荡。复用已有的 W_Q/W_K/W_V，不增参数。

**消融结论（重要）**：单独用 FLA（残差直接相加版 FLT_res）**仍会崩**；单独用
first-layer AI 也不够。**两者必须合用**。只用 FLA → 梯度震荡仍导致崩溃。

### 1.4 他们的局限（我们必须诚实对待）

原文 Limitation 明确写：**"we use a single run per configuration and do not report
training-run error bars"**——即这篇论文也没做多 seed。所以：
- 我们不能拿它当"稳定性已解决"的证据；
- 但它的**诊断框架**（残差范数 + 梯度范数监控）是我们缺的工具。

## 2. 多 seed 报告标准（论文写作必须遵守）

- **统计功效分析**（Colas et al., arXiv:1806.08295）：n=5 的初步研究估计标准差误差可达 σ 本身；
  **推荐 pilot 至少 n=20** 才能得到稳健标准差估计；但深度学习实践中受算力限制。
- **Emergent Mind / 通用报告标准**：至少报告 5 个 seed 的 mean ± std（或 CI）。
- **Deep-significance**（Kaleidophon）：提供 Almost Stochastic Order 检验，
  适用于"多 seed、多数据集"的模型比较，比 t 检验更适合深度网络。
- **Henderson et al. 调查**：被调查的深度 RL 论文**全部用 ≤5 seeds**——说明我们的 n=4 在
  领域常规内，但报告时必须写明 n 与离散度，不能只报最优 seed。

**对我们的直接含义**：
- 当前 n=4、2/4 成功，**不足以做任何"优于基线"的统计主张**；
- 但足以做**机制存在性**主张（"存在解出全部难度的解"是存在性命题，2/4 即可支持）；
- 论文必须区分这两类主张，不能混。

## 3. 为什么我们 1.4M 参数也会不稳？（文献不能直接回答，需自己诊断）

他们的稳定区间（127M/9 loop 不崩）远大于我们（1.4M/8 loop 会崩）。差异候选：

| 候选原因 | 我们的现状 | 是否已排除 |
|---|---|---|
| 学习率过高 | lr=1e-3，AdamW，warmup=steps/50（480 步） | **未排除**——1e-3 对小模型偏高 |
| 梯度累积沿 loop 维 | 8 loop 全展开反传，无 per-loop 梯度裁剪 | **未排除** |
| 残差范数膨胀 | 未测量 | **未排除（最可疑）** |
| h0 每轮重注入 | `inp = carry + h0`，每轮加一次输入 | **未排除**——这会让残差每轮累加 h0 |
| 课程切换的扰动 | cap 2→6 阶梯切换，切换点 loss 跳升（日志常见 6.6、2.5 等尖峰） | **未排除** |
| NoPE（无位置编码） | 已证 NoPE 是承重必要条件 | 不是缺陷，是设计 |

**注意 h0 重注入这一条**：`inp = carry + h0` 每轮都把输入加进残差，8 轮后相当于
h0 被加了 8 次。这正是文献所说 residual explosion 的一个直接来源。
他们的 FLA/AI 方案本质上就是在解决"如何控制跨轮注入的幅度"。

## 4. 建议的诊断实验（按性价比排序，全部本机可做）

### D1. 残差范数与梯度范数监控（最高优先，几乎零成本）
在 s71 的 eval 里记录：`||h_raw||` 逐轮（1..8）、首层 FFN 梯度 L2 范数。
**判据**：失败 seed 是否表现出残差范数随轮次单调膨胀 + 梯度范数尖峰？
- 若是 → 直接对上文献的 residual explosion，可用 AI/FLA 或残差缩放修复；
- 若否 → 排除该假说，转向学习率/课程切换。

这是唯一能把"我们的失败"和"文献现象"确认或排除的观测。**必须先做**。

### D2. 学习率扫描（低成本）
在同一个失败 seed（53）上扫 lr ∈ {3e-4, 5e-4, 1e-3}，看是否能把 0.49 救到 0.9+。
文献通用结论（Kalra 2024 NeurIPS：warmup 降低 sharpness、改善稳定性）支持这个方向。

### D3. 梯度裁剪粒度（低成本）
当前是全局 clip_grad_norm_(1.0)。改为按 loop 轮次分别裁剪，或降低到 0.5。
文献（Pascanu 2013 起）标准做法，但需注意原文指出这是"优化级干预，引入额外超参"。

### D4. 残差注入改造（中成本，D1 证实后才做）
若 D1 证实 residual explosion，按文献实现：
- 最小改动：把 `inp = carry + h0` 改为 `inp = carry + α·h0`（α 可学习或固定 1/√n_rounds）；
- 中等改动：Attention Injection（用上一轮 h 作 Q，当前层作 K/V）；
- 完整改动：FLA + AI 合用（文献证明单独任一都不够）。

### D5. 课程切换平滑化（中成本）
当前 cap 是硬阶梯。可改为按概率混合 cap 与 cap+1，或延长每个 cap 的阶段。

## 5. 结论与行动

1. **文献确认我们的失败模式是已知现象**（gradient oscillation + residual explosion），
   不是我们独有的实现 bug。
2. **但文献的稳定区间远大于我们**，说明我们存在额外的放大因素——最可疑是
   **`inp = carry + h0` 的每轮重注入导致残差累积**，这与文献的 residual explosion 同源。
3. **我们没有测过残差范数**，这是最大诊断缺口。D1 必须先做。
4. **论文写法**：机制存在性（2/4 解出全难度）可主张；稳定性/优于基线不可主张（n=4）。
   引用 2605.18797 作为"循环模型不稳定是领域公认问题"的依据，引用 1806.08295 说明
   n 的统计含义。

**引用清单**：
- Fu et al. 2026, arXiv:2605.18797 — Fully Looped Transformer（诊断 + 修复）
- Colas et al. 2018, arXiv:1806.08295 — How Many Random Seeds?
- Kalra & Barkeshli 2024, NeurIPS — Why Warmup the Learning Rate?
- Saunshi et al. 2025, arXiv:2502.17416 — 循环参数效率（承重背景）
- Geiping et al. 2025, arXiv:2502.05171 — Recurrent Depth（Huginn）
- **Elhady, Agirre & Artetxe 2025, arXiv:2506.00288（ACL 2025）— Emergent Abilities
  under Continued Pretraining**：提出 **Stability Gap**（学习新分布时先丢失旧能力、
  再缓慢恢复或永不恢复），并给出两个验证解法：课程平滑过渡 + **权重 EMA**
  （§5.2：EMA 通过限制参数漂移对抗灾难性遗忘，效果等同混入 20% 旧语言数据）。

## 6. 实测验证结果（2026-10-26，三个假说逐一检验）

### 6.1 D1 残差膨胀假说 —— **证伪**

`s74_ldm_residual_diag.py` 对三个检查点测逐轮残差范数与梯度范数：

| run | 残差轨迹（r1→r8） | 增长倍数 | 梯度均值 | 梯度 CV |
|---|---|---|---|---|
| seed41（成功） | 5.44→36.85 | 6.78× | 1.04 | 0.17 |
| seed53（失败） | 5.04→33.37 | 6.63× | 1.84 | 0.29 |
| seed17（成功） | 5.96→18.16 | 3.05× | 23.07 | 0.25 |

**成功与失败的残差膨胀几乎相同（6.78 vs 6.63）**，且增长最小的 seed17（3.05×）
反而最成功。→ 文献的 residual explosion **不是我们的失败原因**。
梯度 CV 有弱分化（0.293 vs 0.17）但 seed17（成功）的 0.248 落在中间，证据不足。

### 6.2 D2 学习率假说 —— **证伪**

失败 seed53 在三个 lr 下全部失败，且失败模式一致（先到 0.7 左右再崩）：

| lr | 峰值 | 峰值步 | 最终（24k） |
|---|---|---|---|
| 1e-3 | 0.68 | 8k | 0.493 |
| 5e-4 | 0.76 | 12k | 0.509 |
| 3e-4 | 0.729 | 8k | 0.176 |

→ **降低学习率无效**，lr=3e-4 甚至更差。

### 6.3 EMA 假说 —— **部分成立（目前唯一有效的干预）**

失败 seed53 + `--ema-decay 0.99`：

| 配置 | 最终 r8 | hop5 | hop6 |
|---|---|---|---|
| 无 EMA（lr=1e-3） | 0.493 | 0.42 | 0.505 |
| **EMA 0.99** | **0.864** | **0.96** | **0.86** |

**同一 seed 从 0.49 拉到 0.864，hop6 从 0.505 到 0.86，且末段仍在上升。**
→ 文献 arXiv:2506.00288 §5.2 的结论在我们的任务上复现：限制参数漂移能显著对抗
课程推进中的遗忘。

### 6.4 残留问题：hop 间"跷跷板"（EMA 缓解但未消除）

EMA run 的逐 hop 轨迹显示成建制的交替崩溃：

```
12000: hop2=0.10, hop4=0.98     ← hop2 崩，hop4 满
20000: hop4=0.01, hop5=0.99     ← hop4 崩，hop5 满
24000: hop2=0.94 hop3=0.99 hop4=0.57 hop5=0.96 hop6=0.86  ← 幅度减小但仍非全满
```

**hop_k 与 hop_{k+1} 呈跷跷板**——它们分别需要第 k−1 轮与第 k 轮答对，只差一轮。
假说：**共享 core 在同一读出位置要同时服务两个相邻难度，产生轮次索引冲突**
（与 §19.8 hop8 实验的"轮次基准偏移 1"同源）。
EMA 降低了震荡幅度但没消除竞争，说明这是独立于参数漂移的架构因素。

**待验证**：若假说成立，则应能通过「每个 hop 使用独立读出位置」或「轮次索引显式
监督」缓解。另一个更简单的方向是**加宽模型**（增加并行容量以容纳多套映射）。
