# E-003 训练后期精度下滑

**状态**：已定位，已有缓解

## 症状
峰值出现在 20k（r8=0.916），到 24k 掉到 0.786；某 hop 从 0.90 掉到 0.13。

## 复现
exact-T 配方，24k 步，seed41。

## 根因
只监督终轮（exact-T）时，模型没学过"算完继续跑"；后期课程推进后，
状态漂移破坏已学答案（同 E-001）。

## 修法
1. `--persist-sup`（主修法，归零事件 5→0）
2. `--early-stop`（全部 hop ≥0.95 即停，防过冲）
3. 里程碑永久档（hop 首达 0.95 自动留档）
