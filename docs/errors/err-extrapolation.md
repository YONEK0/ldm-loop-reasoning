# E-006 hop7/8 外推恒为随机

**状态**：已定位，未修复

## 症状
`confirm_depth.jsonl`（hop7/8）在任何配置、任何训练步数下都 ≈0.5；
某些种子 hop7 甚至低于随机（0.323）。

## 复现
任意配方训练到 hop6 上限，看 `confirm_r6_by_hop`。

## 根因（部分）
1. 课程上限只到 hop6，模型从未见过 7/8 跳的样本
2. 观测到"hop_k 的答案出现在第 k−1 轮"的基准偏移，说明轮次索引本身可能错位
3. hop7 低于随机提示可能是**评测集偏置**（候选顺序/断链构造），非纯模型失败

## 修法
未解决。下一步：先做 confirm 集只读诊断（候选互换、干扰项选择率、按链重叠分层），
区分"模型不会"与"评测集偏置"。
