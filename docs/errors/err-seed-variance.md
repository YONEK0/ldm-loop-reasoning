# E-002 同一配方换种子结果差异巨大

**状态**：已定位（实为 E-001 的表现）

## 症状
同一配方、同一数据、只换 seed，结果从"五级全解"变成"只到 hop3"。

## 复现
`python s71_ldm_iter4.py --pos none --seed 23` vs `--seed 17`（24k 步，exact-T 配方）

## 根因
不是种子本身，而是 hop5 的"冷启动门槛"（见 H-013）：模型必须先偶然答对一次
才能获得有效梯度。不同种子只是运气不同。修复（persist-sup + step-sup）后
成功率 7/8。

## 修法
`--persist-sup --step-sup`（已验证）
