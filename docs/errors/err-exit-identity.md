# E-004 退出控制器 q 恒为 1.00（永不停止）

**状态**：已确证并修复

## 症状
联训的退出头在 200 样本 × 8 轮中零停轮，q 全部 ≈1.0；硬退出永远跑满 8 轮。

## 根因
`rounds_mask` 冻结使样本过 T 轮后状态不变 → "永远继续"与"在 T 停"的训练损失
严格相等 → 停轮没有梯度。训练在"晚停免费"世界、推理在"晚停有害"世界（语义错配）。

## 修法
改用 PonderNet 完整损失：训练跑满 r_max 不冻结 + 停轮分布 p_t 加权期望 CE
+ 几何先验 KL。已验证可打破 q≡1（但会拖累骨干 hop5/6，最终选 persist-sup 路线）。
