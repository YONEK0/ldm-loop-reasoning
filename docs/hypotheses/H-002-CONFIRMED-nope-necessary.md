# H-002 [已证实] NoPE 是循环承重的必要条件

**假说**：去掉位置编码（NoPE）是出现对角线的必要条件；用正弦位置编码时分（sin）
不会出现对角线。

**证据**（V1 四种子，results/iter4_v1_sin_s1{7,9}.json / iter4_v1_none_s1{7,8}.json）：
- NoPE：seed17 达 4/5 难度全解、seed18 达 5/5
- 正弦：seed17、seed19 均 0/5（对角线不出现）

**机制解释**：绝对位置编码给了"这里是第几个 token"的并行信息，模型可借此
走捷径而非依赖轮次；NoPE 强迫信息只能通过循环状态累积，串行结构才被逼出来。

**复现**：对比 `--pos none` 与 `--pos sin`，其余参数一致。
