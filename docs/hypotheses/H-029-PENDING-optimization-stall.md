# H-029（待验证）：失败 seed 的根因是优化停滞，不是外推能力不足

> 2026-10-28 由 P19 判读引出。数据见 `docs/notes/P19_LONG64K_VERDICT_20261028.md`。

## 假说

13 个 48k 基线的**最终 train task loss** 与 hop7 呈单调关系：

- task loss < 0.15 的 8 个 seed → hop7 全部 ≥ 0.80（PASS）
- task loss ≥ 0.21 的 5 个 seed → hop7 全部 < 0.80（fail）

即"失败 seed"并非"外推能力差"，而是**训练分布都没拟合上**（还有 20–40% 的
训练样本答错）。这是优化停滞问题（初始化 / 早期动力学 / 局部极小），
不是容量或架构问题——同参数下另外 8 个 seed 拟合上了。

|---|---|---|---|
| s67 | 0.0006 | 0.835 | PASS |
| s79 | 0.0027 | 0.825 | PASS |
| s29 | 0.0019 | 0.805 | PASS |
| s11 | 0.0528 | 0.840 | PASS |
| s89 | 0.0707 | 0.900 | PASS |
| s71 | 0.1348 | 0.915 | PASS |
| s83 | 0.1733 | 0.905 | PASS |
| s61 | 0.2392 | 0.895 | PASS |
| s73 | 0.2507 | 0.770 | fail |
| s13 | 0.2267 | 0.765 | fail |
| s53 | 0.2102 | 0.695 | fail |
| s19 | 0.3970 | 0.745 | fail |
| s17 | 0.4134 | 0.740 | fail |

P19 中 s53 把 task loss 从 0.2102 压到 0.0031，hop7 随之 0.695 → 0.805，
与上表一致。

## 关键推论：训练拟合度的上界

拟合到 0.0006–0.0031 的三个 seed（s67/s79/s29）hop7 也只有
0.835 / 0.825 / 0.805。**把训练集背下来并不会带来更强的 hop7 外推。**
即 hop7 的上界约 0.80–0.84，与"外推只靠训练覆盖"的既有结论定量吻合。

## 成因已定位：warmup 长度（2026-10-28 18:25，H2 判读）

**同 seed、同步数（48000）、同配置，只改 `--warmup`：**

| warmup | task loss | hop6 | hop7 | 判定 |
|---|---|---|---|---|
| 960 | 0.2121 | 0.750 | 0.795 | fail |
| 1280 | 0.1079 | **0.915** | **0.890** | **PASS** |

跨两块 GPU 复现：warmup=960 两次（3080 / 5060）全部 fail，
warmup=1280 两次全部 PASS。详见 `docs/notes/H2_WARMUP_VERDICT_20261028.md`。

根因是设计缺陷：原实现 `warm = steps // 50` 把 warmup 与总步数绑死，
导致"48k vs 64k"的对比实际混入了 warmup 变化。已加 `--warmup` 参数修复。

**仍未解决的部分**：warmup=1280 不是保证——两次 w=1280 的 task loss
相差 36 倍（0.0031 vs 0.1079）。它只是提高收敛概率。
其余候选解释（尚未排除）：

1. **warmup 长度**：`warm = steps//50` 使 warmup 与总步数绑死。
   P19 的 s53 在 48k 基线上停滞（task=0.2102），而 `--steps 64000`
   （warmup 1280 vs 960）的同一步数上收敛到 0.0031。**这是唯一的配置差异**，
   故 warmup 是首要嫌疑，但尚未单变量验证（H2 实验进行中）。
2. **初始化/优化混沌**：同配置重跑同 seed 会有不同结果（s53 即为例），
   说明损失地形对早期轨迹极敏感。
3. **课程节奏**：cap 升档时发生部分遗忘（已观察到 cap 升档后 hop4 崩落），
   停滞可能是"升档即遗忘"的净结果。

## 实验设计（待做）

- **H2（进行中）**：seed 53、steps 固定 48000、`--warmup {960, 1280}`，
  分离 warmup 与步数效应。若 Δtask loss ≈ 0.2，则 warmup 是主因。
- **H3（待做）**：对同一 seed 重复跑 5 次（同配置），看 task loss 的分布是
  双峰（收敛/停滞）还是连续。这直接判定"停滞是随机事件还是确定性失败"。
- **H4（待做）**：比较收敛组与停滞组的前 8k 步轨迹（loss、per-hop、熵），
  找早期可分指标。

## 对论文的意义

若证实，论文的核心叙事从"循环能外推"改为更精确的两段式：
**（1）训练能否收敛是概率性事件，决定 hop6 是否达标；
（2）收敛后 hop7 的上界约 0.80–0.84，由训练覆盖深度决定，与拟合精度无关。**
这两点都比原叙事更可复现、更可检验。
