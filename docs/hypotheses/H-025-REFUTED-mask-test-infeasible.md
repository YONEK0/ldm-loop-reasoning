# H-025 [已证伪·检验手段不成立] 用邻接掩码检验"每轮一跳"在本架构下不可行

## 背景

当前 MVT-D v2 上，模型在 **r=2 就饱和**（r=3–8 无增益），
说明它用压缩式推理（一轮传播多跳），不是"每轮推进一跳"。
因此该任务**无法检验**"循环承载串行深度"。

诊断（2026-10-27 22:30）：把训练好的模型（无掩码，h6=0.900）
在推理时加上事实级邻接掩码（第 t 轮只能看 ≤t 跳），
h3–h6 从 0.90 掉到 0.55–0.68 —— 提示模型确实依赖跨跳直接注意力。
但模型是无掩码训练的，此结果只是提示，不是证明。

## 假说

**给训练时施加拓扑掩码后，会出现真正的"每轮一跳"阶梯：
r < h 时物理上不可能答对，r ≥ h 时跳到高准确率。**

## 实现（`s88_adj_task.py` + `--adj-mask`）

事实级邻接：`fact i` 的 obj == `fact j` 的 subj → 一跳边。
第 t 轮，事实位置只能看到 ≤ t 跳内的事实；候选/任务标记不受限。
hop h 的答案需从 e0 走 h 跳，故至少需 h 轮。

## 预注册判据

- **成立**：
  1. `r < h` 时准确率 ≤ 0.55（接近随机）；
  2. `r ≥ h` 时准确率 ≥ 0.85；
  3. 转折点随 h 平移：`r*(h)` 关于 h 严格单调递增。
- **部分**：出现 r 依赖，但 `r*(h)` 与 h 无单调关系。
- **不成立**：
  1. r 扫描仍平坦（无阶梯）；**或**
  2. 模型完全学不动（loss 不降、所有 r 都 ≈ 0.5）。

第二类"不成立"同样有意义：说明该架构在"每轮一跳"约束下无法工作，
"压缩式推理"是它唯一可行的模式。

## 判定（2026-10-28 10:45）

**结论：该检验路径不成立（REFUTED），不是"阶梯不存在"。**

三个变体实测：

| 变体 | 做法 | 结果 |
|---|---|---|
| A | 第 t 轮看 ≤t 跳 | r=3 解 hop6（0.99）→ 未约束住 |
| B | 每轮 1 跳 | loss 2.11 恒定，全 r 随机；hop2–3 也学不会 |
| C | BFS 距离分层（候选只看 dist≤t−1） | 5000 步 hop2 在 r=2/r=8 均 0.50 |

**根因**：本任务图节点是"事实"、候选是"实体"，两者不在同一张图里。
掩码只能约束事实→事实，无法约束"实体候选如何读到这些事实"：
候选全可见 → 约束失效（A）；候选受限 → 实体与事实链无法对齐（C）。

Chen 2026（arXiv:2603.21676）的掩码有效，因其**节点即实体、读出为节点对**，
源与目标同图、掩码一致生效。

**影响**：核心假说"循环承载串行深度"**仍缺直接证据**，但本项目不再试图
用该方法检验。论文口径改为"压缩式多步推理"（见 PAPER_SKELETON v3）。
