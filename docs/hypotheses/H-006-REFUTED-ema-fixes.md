# H-006 [已证伪] EMA 可修复训练不稳定

**假说来源**：arXiv:2506.00288 §5.2 指出权重 EMA 通过限制参数漂移对抗
灾难性遗忘（Stability Gap）。

**判定方式**：`--ema-decay 0.99`，在三个种子上对照。

**结果**：

| seed | 无 EMA 最终 | EMA 最终 | 变化 |
|---|---|---|---|
| 53 | 0.493 | **0.864** | 大幅改善 |
| 31 | 0.732 | 0.673 | 略差 |
| 17 | 全解（5/5） | **0.691**（hop5=0.11, hop6=1.0） | **大幅变差** |

**证伪理由**：EMA 把 seed53 从 0.49 拉到 0.86，但把原本成功的 seed17 从
"五级全解"打到 0.691。净效果为零或负。

**重要的副产品**：EMA run 暴露了跷跷板现象（hop5=0.0 与 hop6=1.0 同时出现），
这是 H-007 的强证据。

**结论**：EMA 不是解法，但它是**观测工具**——它让跷跷板从"偶尔崩"变成
"持续可见"，从而暴露了真正的结构问题。
