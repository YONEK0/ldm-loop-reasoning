# H-004 [已证伪] 残差爆炸导致训练失败

**假说来源**：arXiv:2605.18797 指出循环 Transformer 训练不稳的两个来源之一是
residual explosion（残差范数随 loop 数膨胀）。

**判定方式**：`s74_ldm_residual_diag.py` 测量三个检查点的逐轮残差范数与梯度范数。

**结果**：

| run | 残差轨迹（r1→r8） | 增长倍数 | 梯度均值 | 梯度 CV |
|---|---|---|---|---|
| seed41（成功） | 5.44→36.85 | 6.78× | 1.04 | 0.17 |
| seed53（失败） | 5.04→33.37 | 6.63× | 1.84 | 0.29 |
| seed17（成功） | 5.96→18.16 | 3.05× | 23.07 | 0.25 |

**证伪理由**：成功与失败的残差增长几乎相同（6.78 vs 6.63），且增长最小的种子
（seed17, 3.05×）反而最成功。残差范数无区分度。

**保留的弱信号**：梯度 CV 有弱分化（失败 0.293 vs 成功 0.17），但另一个成功种子
（seed17）为 0.248 落在中间，不足以支持。

**结论**：residual explosion 不是本任务失败的原因；这条文献解释不适用于
1.4M 参数/8 轮/NoPE 的配置。
