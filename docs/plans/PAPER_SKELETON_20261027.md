## 摘要口径（v3）

1. **机制**：1.47M 单层共享循环在无捷径的多跳任务上能解 4 跳外推（hop7/8 均达 0.80+，
   训练只到 hop6），且 **r=1 恒为随机**（三 seed 一致）→ 循环被真实使用。
2. **但**：能力在 **r=2–3 就饱和**，r 更大无增益；hop7 在 r≤8 下达成，远少于跳数
   → **压缩式**（一轮推进多跳），非"每轮一跳"。
3. **不可能归因于容量**：同任务上 dense mid=1/3/5（1.40M/2.29M/3.18M）
   loss 精确停在 ln2，参数 ×2.3 无效；loop 1.47M 可达 0.90+。
4. **方法**：Ouro 式均匀先验 + 熵正则（`--ouro`）显著优于固定轮数监督：
   成功率 2/2 vs 1/3，全指标更高，12k 即达 persist 24k 水平。
5. **边界**：深度外推靠"训练覆盖"，不是"练得更久"——同 step 处 24k 与 48k
   完全相同，48k 的收益来自课程走到了 hop6。
6. **限制**：seed 方差大（48k 下 h7≥0.80 仅 3/7）；"每轮一跳"未获证实，
   且在本架构下不可检验（节点=事实、候选=实体，掩码无法约束读出路径）。

## 论文中应避免的表述

- ❌ "循环承载串行深度/每轮推进一跳" → 无证据，且检验路径已被排除
- ❌ "参数效率优于稠密" → 实为"稠密结构上做不到"，措辞要改成能力而非效率
- ❌ 任何基于 MVT-5 的结论（任务有 100% 捷径，见 H-023）

## 可写的相对结论

- "循环提供的计算在 r=2–3 饱和；更多轮不带来增益"
- "训练覆盖到深度 d 是解 d 跳的必要条件；仅延长训练而不扩展覆盖无效"

## 一、当前可写的内容（仍成立）

### A0. 核心正面结果（本轮新增，最可信）

**在消除任务捷径的 MVT-D v2 上，1.47M 单层循环模型学会了必须多轮才能解的任务，
并从训练深度 6 外推到未训练的 7/8。**

| 证据 | 数值 |
|---|---|
| r=1（单轮） | **0.506（随机）** — 所有 3 个 seed 一致 |
| r=2 | 0.868（s71） |
| r≥3 | 0.88 |
| hop7（未训练） | **0.830** |
| hop8（未训练） | **0.785** |

**最关键的一点：r=1 永远是随机。** 若任务可用单步注意力解决，
至少某些 seed 会在 r=1 取得部分正确率。三个 seed 在 r=1 上都是 0.49–0.51，
说明**单轮在物理上不可能解此任务**，循环确实被用于计算。

**发育序列**（s71）：12k 步时 r=8 先到 0.702 而 r=1/r=2 仍随机；
18–24k 低轮数才追上。**高轮数先会、低轮数后会**——与捷径模型
（r=1 就 0.88）完全相反。

### B. 方法学贡献（本轮的真正产出）

**题目候选**：
- *Shortcut Audits for Synthetic Reasoning Benchmarks: A Case Study in Looped Transformers*
- *When 98% Accuracy Means Nothing: Task-Level Shortcuts in Multi-Hop Reasoning Evaluation*

**核心论点**：
1. 合成多跳任务极易引入"不需要求解"的捷径；
2. 这类捷径**不会**在 loss 曲线、by-difficulty 指标上显现；
3. 唯一可靠的检测是**物理约束检验**（如"r 轮最多推进 r 跳"）+
   **最简单启发式规则测试**；
4. 本项目实例：一条不看输入的规则在 19750 个样本上 100% 正确，
   导致模型"全解"的表象；去捷径后所有模型跌到随机。

**可报告的实证**：
| 检验 | 有捷径 | 去捷径 |
|---|---|---|
| persist+step，hop4 | 1.000 | 0.607 |
| persist+step，hop6 | 0.995 | 0.520 |
| exact-T，hop7@r6 | 0.787 | 0.535 |
| MVT-D v1 训练（有入边捷径） | 0.981 | — |
| MVT-D v2 训练（无捷径） | **0.501（学不动）** | — |

### C. 负面结果（有价值）

**在无捷径的纯链路径追踪任务上，1.47M 单层循环模型 + persist/step 监督
完全无法拟合（loss 停在 ln2 附近，准确率 = 随机）。**

这本身是一个可发表的边界：说明"小循环模型能学会多跳"这个说法需要
严格的任务设计才能成立，而此前文献中的正面结果可能也有类似问题。

## 三、下一步实验计划（按优先级）

### P0：确认 MVT-D v2 是否可学

- 当前 3 seed 跑到 6k，全部 0.50。若 24k 仍不学：
  - **降难度**：训练 hop 只到 4（当前 2–6），看 hop4 能否学会；
  - **加归纳偏置**：邻接掩码（Chen 2026 arXiv:2603.21676 的
    topological interface），使每轮只能沿边传播一跳；
  - **换监督**：exact-T（Chen 的 silent thinking）+ 随机 T，看是否比
    persist+step 更适合真求解。

### P1：在可学的任务上重建阶梯

一旦有任务能学，立刻做 r 扫描，判据（预注册）：
- hop h 的最优 r 满足 r*(h) 随 h 单调递增，且 r*(h) > r*(h−1) + 0.5；
- 且 r*(h) ≈ h（或 h−1，取决于任务约定）。

### P2：重做参数效率

loop vs dense 在**同一个可学任务**上对比，控制参数量与训练步数。

## 五、方法学章节要点（本轮教训，必须写进论文）

1. **任务审计先于模型实验**：任何新合成任务，先跑 5–10 条朴素启发式，
   若某条接近满分，任务无区分力。
2. **物理约束检验**：用任务的内在约束（如"每轮最多一跳"）反推
   "什么分数在物理上不可能"，比看 loss 更能暴露问题。
3. **去捷径对照集**：保持任务语义、消除可利用的统计规律，复测现有模型。
4. **报告"模型在无捷径任务上的表现"**，而不只是原任务分数。
