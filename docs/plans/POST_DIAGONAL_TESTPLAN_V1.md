## V1 坐实：NoPE 消融 × 多种子（6 run，双流 ~1.5h）

- 配置：{pos: none, sin} × seed {17,18,19}，s71 24k 步（与 §18.3 同配方）。
- **预注册判据**：对角线复现 = 5 个 hop（2–6）中 ≥4 个满足 acc(r=T−1) ≥ 0.9 且非匹配轮均值 ≤ 0.6；
  - NoPE 因子成立 = none 在 ≥2/3 种子复现 且 sin 在 ≥2/3 种子不复现；
  - NoPE 非必要 = sin 亦复现（承重更稳，归因改写）；
  - 均不复现 = §18.3 为种子偶然，退回未证实。
- 产物：`results/iter4_v1_{pos}_s{seed}.json`（含逐 hop × 逐 r + ckpt）

## V2 参数效率对照：iso-param dense 臂（2 run，~40 分钟）

- 配置：dense（无循环，混批同数据流）mid=1（3 块 ≈ loop 唯一参数量级，容量 3 查找）与 mid=3（5 块，容量 ~5，参数 ~1.7×）；同 20k 步。
- **预注册判据**：
  - 参数效率主张成立 = dense-mid1 在 hop5/6 <0.7（容量不足实证）而 loop 对角线 ≥0.9（§18.3/V1）；且 dense-mid3 若解开 hop5/6 → "loop 以 1× 参数解开需 1.7× 参数的深度"（参数口径收益，算力口径 loop 更贵：r=5 是 7 块遍历 vs dense 5——如实报告）；
  - dense-mid1 若解开 hop5/6 → 单遍并行容量被低估，参数主张不成立，如实记录。
- 附带：记录 dense 各 hop 精度作论文对照表。

## V3 兑现：退出控制器接回（省算力实测，2 run，~1h）

- V3a（先跑）：在 V1 最优 ckpt 上训练退出控制器（s67 框架，逐轮置信度 + 轮次嵌入，λ 退火），硬退出推理评测（τ 扫描）。
- **预注册判据**：硬退出精度 ≥ oracle 对角线 −2pp；mean_rounds ≤ E[T]+0.5（E[T]=3）；vs 固定 r=8 节省 ≥50%；按 hop 停轮分布与 T 一致率 ≥0.9。
- **诚实标注**：MVT-5 的 hop 可从 goal 长度直接读出——退出若走"读题面深度"捷径属合法但平凡（记录停轮依据分析）；因此加：
- V3b（清洗版）：MVT-3（断链深度逐实例变化）+ exact-T（per-sample T=断链深度+1，与题面 hop 无关）——真·难度推断退出。判据同 V3a，此为非平凡版；若 V3b 对角线不成（MVT-3 曾在 D8 下失败）则记录并归因。
