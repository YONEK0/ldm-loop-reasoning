## 1. 首轮要回答的问题

首轮仅验证机制可行性，不主张参数效率：

1. 同一模型的共享循环核心能否通过多轮计算解决需要多跳组合的决策题？
2. 在质量已学到后，训练出的样本级退出控制器能否让不同难度样本使用不同轮数？
3. 与固定深度模型相比，自适应退出能否在预先设定的质量容差内实际减少循环核心调用？

不回答“循环模型是否比同参数或同算力稠密模型更省参数”。要回答该问题，须另做至少三臂、多规模、重复种子的参数效率实验。

## 3. 任务接口建议

### 3.1 单个决策样本

建议复用 T-13 的图生成器和唯一解求解器，但重新定义决策目标。

**关键设计约束（V1.1 冻结，源于 T-13 函数式图的退化分析）**：T-13 的图为函数式（每实体每种关系至多一条出边），若直接在其上做"选下一条边"，正确动作只由目标路径首关系唯一决定，无需任何多跳追踪。因此本任务必须使用**非函数式图**：当前实体存在多条同关系候选边；仅一条能沿目标路径完整走通（其余在路径不同深度断链，断链深度构成第二条难度轴）。动作唯一性由求解器显式校验：所有候选中恰有一条使答案实体可达。

- **状态**：一组无序关系事实组成的有限图，以及当前实体。
- **目标**：一条关系查询/目标路径，例如连续的关系约束；任务生成器保证存在且仅存在一个满足条件的解路径。
- **候选动作**：从当前实体出发的一组候选边 `(relation, next_entity)`，包含正确边和由图结构生成的干扰边。
- **标签**：唯一正确候选动作的索引。候选集合顺序逐样本随机化；动作身份而非位置决定标签。
- **输出**：每个候选动作一个 logit；argmax 为选择动作。

决策被定义为“选下一条边”，而不是直接预测最终目标实体。这样多跳推理需在内部状态中组合关系链，同时输出仍为单步决策，不会与文本生成长度/EOS 混杂。第一版仅监督当前一步正确动作；是否加入多步 rollout 属于后续扩展，不纳入最小试验。

### 3.2 数据切分与审计

切分沿用 T-13 的难度轴思路，但数据须为新任务重新生成并重新审计：

- `train`：训练范围内的关系组合和路径深度。
- `dev_random`：同分布随机验证，用于选择 checkpoint 和训练阶段控制。
- `confirm_depth`：训练未出现的更深路径，测试深度外推。
- `confirm_combo`：留出关系组合或查询模板，测试组合外推。
- `confirm_distractor`：训练中未出现的更高干扰边/候选动作数量，测试输入长度与干扰鲁棒性。

确认集在规格冻结时一次性生成并锁定；训练期间不得用于调参、早停、损失设计或阈值选择。若确认集结果促成任何设计改变，应另行生成新确认集并把旧集标记为已消耗。

生成前置条件：每题唯一正确动作；至少一个正确动作和一个错误候选；候选数、正确动作位置、实体编号与关系频率在切分间平衡；规范化图/状态/候选集合去重；跨切分检查图同构或等价状态泄漏；保存生成器版本、随机种子、数据哈希和求解器审计结果。T-13 旧数据的唯一答案检查与 ID 级泄漏检查可复用代码模式，但旧数据并非本任务的已验证数据集。

### 3.3 输入编码

首选结构化符号序列，避免依赖预训练自然语言词汇：

`[STATE] (subj, rel, obj)* [CURRENT] entity [GOAL] rel* [ACTIONS] [ACT] rel entity ...`

实体编号、关系、分隔符、候选动作标记使用从头训练的 embedding。事实和候选顺序独立随机打乱；每个候选动作有独立 `[ACT]` 标记。填充位置用 attention mask 排除。超过最大上下文的样本计入长度切分，不能静默截断关键事实或候选。

## 4. 模型规格建议

### 4.1 拓扑

`Embedding/Encoder → Prelude → Recurrent Core（共享权重）→ Coda → Candidate Scorer`

- **Prelude**：1 个普通 pre-norm Transformer block，产生 `H0 ∈ R^(B×S×d)`。
- **Recurrent Core**：2 个普通 pre-norm Transformer block，所有循环轮次复用同一组参数。
- **输入注入**：每轮 core 输入 `H_t + H0`；残差、归一化和位置编码规则在实现规格中逐项定义，避免重复叠加绝对位置编码。
- **Coda**：1 个普通 pre-norm Transformer block，仅在最终决策表示计算；循环中的轻量 probe 不运行完整 Coda。
- **候选评分**：共享评分器读取每个 `[ACT]` 位置的隐藏状态，并以共享线性/小型 MLP 产生一个 logit。候选数可变；padding 候选屏蔽。
- **退出控制器**：共享的小型 MLP，按样本读取当前轮 pooled hidden、轮次嵌入、probe 的置信度特征及与前轮 probe 分布的变化特征，输出 `q_t = P(继续 | H_t)`。

### 4.2 小型起始尺寸（估算值，不是已确认配置）

| 项目 | 暂定值 |
|---|---:|
| 隐藏宽度 `d` | 192 |
| 注意力头数 | 4（每头 48 维） |
| FFN 宽度 | 768（扩展倍率 4） |
| Prelude/Core/Coda 逻辑块 | 1 / 2 / 1 |
| 循环轮数 | `R_min=1`, `R_max=6`，硬上限 6 |
| 最大输入长度 | 先由生成数据长度分位数确定，不先定死 |
| 参数量 | 约 2M 量级，需按实际词表、归一化、embedding tying 和控制器实现重新计算 |

普通 Transformer 是首轮建议，理由是实验目标在循环机制而非复现 GDN。**V1.2 修正**：循环块输出投影改为小方差初始化（std=0.02），而非讨论文档 D7 原定的精确零初始化——实测精确零会使 qkv/up/ln 梯度全为 0，可训练容量塌缩（`LDM_CAMPAIGN_LOG.md` §4.1）。"初值接近恒等"的稳定意图保留，但不以切断梯度为代价。

### 4.3 多轮与评分

令 `H0 = Prelude(X)`，`H_t = Core(H_(t-1) + H0)`。每轮轻量 probe 只用于退出和训练辅助监督；退出轮 `t*` 的最终输出为 `score_t* = CandidateScorer(Coda(H_t*))`。

训练期可选择在每轮都施加动作分类监督，以让较浅深度也有可用输出。首轮建议使用深度均衡的轮次采样/损失权重，不能让最大深度样本主导全部梯度。验证时必须同时报告每一深度独立运行的固定深度质量。

## 5. 退出机制与训练损失

### 5.1 两种语义必须分开报告

- **训练代理**：为了让退出控制器收到梯度，可对所有轮次计算软 continuation / exit 权重。该训练过程即使使用软权重，也可能实际执行全部最大轮数，不能把它称为推理省算。
- **推理执行**：样本级控制器在每轮后决定是否继续；一旦退出，必须真正不执行后续 core blocks。报告实际执行的 core 轮数、核心 FLOPs 或经 profiler 计数的运算量。软路由的期望轮数只作为代理指标。

### 5.2 可微训练定义（建议）

对样本 `i`，令继续概率为 `q_(i,t) = sigmoid(g(H_(i,t), t, z_(i,t)))`，其中 `z` 为 probe 特征。定义存活质量 `s_(i,1)=1`，`s_(i,t+1)=s_(i,t) q_(i,t)`；退出权重 `w_(i,t)=s_(i,t)(1-q_(i,t))`，末轮把剩余质量并入 `w_(i,Rmax)`，保证权重和为 1。

暂定目标：

`L = Σ_t w_t CE_t + α Σ_t a_t CE_t + λ(step) E[R]`

其中第一项是按退出分布加权的决策损失；第二项是较浅轮次辅助监督，`a_t` 总和为 1；`E[R]=Σ_t s_t` 是期望执行轮数。`α` 的作用及是否保留需要在固定深度预实验中确认。禁止无依据复制 S08 的语言建模 KL 项或数值超参数。

### 5.3 质量 warm-up 和成本退火

建议分阶段，而不是从第一步就强推少算：

1. **固定深度质量阶段**：不训练控制器，不施加 ponder 惩罚。比较 1、2、4、6 轮能否学会任务；确定可用深度及训练信号。
2. **退出 warm-up 阶段**：从固定深度已达到质量门槛的 checkpoint 初始化 core；打开 continuation 训练，但 `λ=0`，先确认退出控制器有非零梯度并能复现质量。
3. **成本退火阶段**：从 `λ=0` 平滑增至预注册的 `λ_max`；每个检查点同时报告质量和期望/真实轮数。若质量越过容差，回滚到最近通过的 λ，而不是只报告最省算的点。

阶段边界、训练步数和具体 λ 曲线必须由短程纯 CPU/单步 sizing 及任务 pilot 后写进 P0 注册；此草案不把 S08 的 300-step warm-up 或 `λ_max=0.02` 照搬到新任务。

### 5.4 硬退出规则（待确认）

推荐首轮采用简单可审计的概率阈值：达到 `R_min` 后，若 `P(stop)=1-q_t ≥ τ_stop` 则退出；否则继续，最迟 `R_max` 强制退出。阈值只在 `dev_random` 上选定并冻结。还应报告各轮退出率、置信度、准确率与难度的关系。

KL + 熵双条件目前是文献启发的候选，不应未经验证作为首版硬停止规则。建议先将 probe 分布 KL、熵和 logit margin 作为分析指标；若控制器只学到“总在最早轮退出”或“总到上限”，再单独注册停止规则消融。训练用 probe 和推理时最终 scorer 必须共享定义，或通过一致性损失显式校准，不能把二者等同而不验证。

## 6. 首轮对照与评测

### 6.1 最小对照

1. **固定 1 轮**：无额外循环的参考质量。
2. **固定多轮**：相同初始化/训练数据下运行指定深度（建议候选 4 轮；另报告 2/6 轮深度曲线）。
3. **自适应退出**：共享 core，训练退出控制器及成本项，推理时真实跳过后续轮次。
4. **同参数稠密诊断臂（建议）**：从头训练、参数量匹配，用于判断当前任务是否只需普通深度；不扩展成同算力对照，不据此发布参数效率结论。

如果只允许最小成本，前三项是机制验证最低集合；若固定多轮都不能超过单轮，先判为任务/训练信号未建立，不进入退出训练。对照训练预算、数据顺序、优化器和 checkpoint 选择规则需匹配并预注册。

### 6.2 指标

- 主要质量：动作 top-1 accuracy、macro accuracy（若标签/动作频率不均衡），按路径深度、候选数、干扰量、关系组合分层。
- 主要计算：实际平均循环轮数、轮数分布、循环 core 调用数；补充估算 FLOPs/样本和 wall-clock latency。
- 退出行为：轮数与难度/错误概率/置信度的关联；固定深度与自适应的质量-轮数曲线；最早轮、最晚轮占比。
- 稳定性：训练/验证曲线、梯度范数、数值异常、随机种子间均值和离散度。
- 数据完整性：唯一正确动作率、候选位置均衡、状态/图重复与跨切分等价样本检查结果。

首轮建议至少 3 个独立种子评估关键 arm；单种子只作为流程 pilot，不作稳定性结论。确认集只在规格锁定、checkpoint/阈值选择完成后评一次。

### 6.3 暂定通过门槛（须确认后预注册）

- **任务可学**：固定多轮在 `dev_random` 明显高于多数类/随机基线，并在确认集至少保留随难度合理下降的可测性能；若训练集高而随机验证不升，判数据/优化故障。
- **循环信号**：固定多轮相对固定 1 轮的配对差异方向为正，且按种子报告不确定性；不以单一最好种子作通过判据。
- **退出学会分配计算**：自适应平均真实轮数低于固定多轮，难样本平均轮数不低于易样本，且不能靠全部样本在第一轮/最后一轮的退化策略过关。
- **质量约束**：自适应相对固定多轮质量下降不超过预先确认的容差；建议初始讨论值为 2 个百分点，不能当作已批准门槛。
- 任何门槛未通过时，结论应定位为任务、可训练性或控制器失败；不以继续增大模型/预算掩盖失败。

## 7. 参数与计算核算口径

- 参数效率中的“参数”若未来要研究，主口径为**从随机初始化训练且参与学习的独立可训练参数量**；循环复用权重只计一次。Embedding、输出头、控制器、归一化参数均纳入总数，并单列 core 参数。
- 本轮机制实验同时报告参数总量和唯一 core 参数；不以单次前向展开中重复调用的权重次数冒充参数量。
- 计算量按每个样本实际执行的 core 调用数统计；每轮调用的 block 数固定时，理论主项与执行轮数线性关联。另计 Prelude、probe、Coda、候选 scorer 的开销，不能把它们从自适应 arm 的成本中剔除。
- 训练 soft exit 若仍完整执行最大深度，训练 FLOPs 按真实完整执行报告；不得用 `E[R]` 代替实际训练成本。
- 测时应区分吞吐、单样本延迟与批处理效率；不把 E2/E3 的 S08 推理速度直接外推到新架构。

## 8. 预算与实施边界

当前环境资料显示本机 8GB 笔记本 GPU 曾发生显存紧张和热降频；T-14 的约 25 分钟是小规模 LoRA、200 step cell，不是从头训练估时。因此本草案不承诺 GPU 训练时长，也不据此安排完整 GPU 运行。

在任何训练授权前应先完成：数据生成器 CPU 单测/去重审计、模型参数量与单步显存 sizing、短程 pilot 的预估；提交硬件、显存余量、最大步数、墙钟上限与停止条件。超过 8GB 可用显存或发现显存 thrashing 时应停止并调整规格，不在运行中临时扩大预算。

授权边界：本文只是方案草案。即使用户确认设计，也不自动授权训练、使用 GPU、长时间运行、下载模型/数据或覆盖任何现有结果；这些行动须另有明确范围授权。

## 9. 风险与需防止的错误结论

| 风险 | 控制措施 |
|---|---|
| 候选位置成为捷径 | 每例随机排列，跨切分位置均衡，报告按位置分组指标 |
| 多跳标签实际不唯一 | 由确定性求解器验证唯一正确动作，生成失败样本丢弃并计数 |
| 训练/确认图结构泄漏 | canonical graph/state/action-set 去重，并加等价图检查 |
| 模型仅记忆实体或模板 | 实体编号重映射、模板/关系组合留出、深度外推确认 |
| 多轮监督造成浅轮负迁移 | 单独报告固定深度曲线；辅助损失系数预注册并消融 |
| 控制器塌缩为固定深度 | 记录分轮退出直方图、难度条件轮数与控制器梯度 |
| 软退出被误报为实际省算 | 训练和推理成本分开记；推理 profiler 确认后续 core 未执行 |
| 单任务被误报为通用能力 | 明确结论限定在该合成决策任务；后续增加任务族及通用对照 |
| 从头训练结果与适配结果混淆 | 新实验独立权重、目录、数据和证据链；不混入 S08 权重 |
