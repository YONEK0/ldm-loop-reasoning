## 0. 为什么要重写（一段话说清）

文献核读（§31）证明了两件事：第一，**循环深度的"算力收益"在文献中只有两种
合法主张**——(a) 相对自身满深度的节省（MoR 框架），(b) 参数效率（Huginn
框架：少参数+多重复计算 ≈ 大模型质量）；**没有任何一篇主张"推理时比同质量
单遍模型更省"**。第二，深度收益的存在性是**训练出来的前提**——Huginn 的
模型去掉深度会塌（r=1 时 GSM8K 0%），我们的模型去掉深度不变（d1≈d2≈d8
全平），说明我们的训练从未让模型需要深度。此前所有成本比较（1.49×/2.9×
等）都在"深度无收益区间"里测成本，结论无效（用户 2026-10-22 指出"忽略
优势区间"，成立）。

## 1. 命题重写（只测这两个）

### 命题 A（省算力，合法版）
> 在**深度有质量收益**的任务上，自适应退出能以满深度（d=max）的质量为
> 基准，用显著更少的平均深度达到同等质量。

- 文献对应：MoR（vs 自身满深度）；LoopUS 的 confidence stopping（3.39/8
  圈保持最优深度质量）。
- 报告形式：**accuracy-vs-r 曲线**（x=固定深度 d∈{1,2,4,8}，y=strict），
  曲线上标注自适应点的 (d̄, acc)。省算力 = (max−d̄)/max 的圈数节省，
  只在自适应点与最优固定点质量配平时成立。
- **不测**：与单遍 armA 的全任务成本比（已证明无意义，数据见 §29）。

### 命题 B（参数效率，可选）
> 0.8B 循环模型在 d=d̄ 时的质量，相当于 N 倍参数的稠密模型。

- 文献对应：Huginn（3.5B/r=32 ≈ 30-50B 等效算力的质量）。
- 测法：质量-vs-参数量阶梯（0.6B/0.8B/1.7B/4B 同协议），看循环模型
  的质量打在哪个参数档。**零训练成本**（Qwen3-0.6B/1.7B 已在缓存）。
- 优先级低于命题 A（先证明深度有用，再谈参数效率）。

## 2. 指标体系（文献标准）

### 2.1 必报指标
| 指标 | 定义 | 文献出处 |
|---|---|---|
| accuracy-vs-r 曲线 | 固定深度 d∈{1,2,3,4,6,8} 的 strict 准确率 | Huginn Fig.7、LoopUS Fig.5 |
| 自适应点 (d̄, acc) | 路由器实际平均深度 + 对应质量 | LoopUS §4.4（3.39/8） |
| 深度收益 Δdepth | acc(d=max) − acc(d=1) | Huginn Table 4（孪生对比） |
| 圈数节省 | (max − d̄)/max，仅当质量配平 | MoR |
| 生成长度分布 | mean/p50/gen_tokens + EOS 率 | 我们已有（T-7 口径） |

### 2.2 记账纪律（修正此前错误）
- 每次只报**单一维度**（深度、质量、长度），**禁止合成单一"成本倍数"**；
- 层调用只用于 **decode 段同任务相对比较**，不跨段（prefill/decode）相加，
  不跨任务外推；
- 探针（若有）**单列**并标注为策略开销，不进架构账；
- 墙钟只在有完整 KV cache 的路径上测（0.8B 已具备；4B 需先补 M 块
  cache）；
- 训练/评测数据集必须分开；GSM8K test 永不用于调参。

### 2.3 显式禁止（踩过的坑）
- 禁止把 prompt 处理成本与 decode 成本按同一权重相加（并行 vs 串行，
  墙钟差 3–5×）；
- 禁止在深度无收益的任务上报"省算力"结论；
- 禁止把工程停止规则（stop-string）称为自然 EOS。

## 3. 训练数据：换（核心变更）

### 3.1 为什么 GSM8K 训不出深度依赖
- rationale 平均 ~130 token、单步推理（一个等式链即得答案）；
- d1≈d2≈d8 质量全平（40 题 n=100 反复验证）；
- 结论：**数据不含"需要多圈潜计算"的结构**。

### 3.2 主选：ProsQA（本地已有，17,886 训练 / 300 验证 / 500 测试）
- **任务结构**：随机 DAG 上的逻辑推理，每题需在干扰分支中搜索 3–5 步
  路径——天然的"多步依赖"；
- **文献先例**：Coconut（2412.06769）在该任务上证明潜推理胜过显式 CoT
  （97.0% vs 77.5%），是唯一有此结论的题集；
- **与命题的契合**：每一步 DAG 推进对应潜空间一次迭代——深度收益
  Δdepth 应显著 >0；若连 ProsQA 都训不出 Δdepth，则整个 0.8B 循环
  路线可以诚实否定；
- **评分**：answer 句子精确匹配（answer 字段），无生成解析歧义；
- **无污染**：合成数据（生成式 DAG），不在任何预训练语料中。

### 3.3 训练配方变更（相对 S08）
| 项 | S08（旧） | 新（ProsQA） | 理由 |
|---|---|---|---|
| 数据 | GSM8K+wiki 7:3 | ProsQA train 17,886 题 | 深度依赖来源 |
| 深度采样 | 主深度 d2（armB） | **均匀/对数均匀采样 d∈{1..8}**，高均值 | Huginn：训练时高 r̄ → 推理时深度有用 |
| 监督 | K=2 随机圈 | K=4，加大监督覆盖 | 让每个深度档都有梯度 |
| 验证集 | GSM8K val | ProsQA valid 300 | 同分布 |
| 保留 | EOS 混合补丁（T-7 配方） | 同 | 自然终止已解决 |

### 3.4 备选（若 ProsQA 训不出 Δdepth）
- 多跳数学（需要外部数据集，先不引入）；
- 诚实否定路线：0.8B 规模 + retrofit 场景下深度无收益，转参数效率
  （命题 B）。

## 4. 实验分阶段（门禁制，每阶段需授权）

### P1-0：基线与孪生（~60 卡·分钟，一次性）
- 裸 0.8B Base 在 ProsQA valid 300 上的 few-shot CoT / direct 两条基线；
- **产出**：CoT-off / CoT-on 的质量与长度锚点（对应 T-11 的 4B 版，
  这次在 0.8B 上做，为训练目标提供参照）。
- **门禁**：无（纯测量）。

### P1-1：循环训练 ProsQA（~2-4 小时，8GB 卡）
- S08 架构不变（E4+M12+D8，LoRA r16，l1gate），数据换 ProsQA，深度
  均匀采样；
- 每 100 步存档 + ProsQA valid 上 d∈{1,2,4,8} 快评（CE + 少样本
  生成）；
- **门禁 G1（深度收益存在性，硬闸）**：valid 上 strict(d=8) −
  strict(d=1) ≥ 10pp 且配对 CI 不含 0。
  - **不过** → 记录并停止（结论：0.8B retrofit 训不出深度依赖），
    转命题 B 或升 4B；
  - **过** → 进 P1-2。

### P1-2：accuracy-vs-r 曲线 + 自适应退出账（~90 卡·分钟）
- 固定深度 d∈{1,2,3,4,6,8} 全曲线（valid 300 或 test 500）；
- 路由器（重训或沿用 qat 谱系）自适应点 (d̄, acc)；
- 命题 A 判定：自适应点质量 ≥ 最优固定点 −2pp 时，报告圈数节省
  (8−d̄)/8；
- 生成长度 + EOS 率（T-7 口径）；
- **产出**：论文主图（accuracy-vs-r + 自适应点标注）。

### P1-3（可选）：参数效率阶梯（~40 卡·分钟，零训练）
- Qwen3-0.6B / 1.7B / 4B-Base 同协议 ProsQA few-shot；
- 循环 0.8B 的质量定位在哪个参数档 → 命题 B 的答案。

### P1-4：4B 复刻与升腾决策（需单独授权）
- 前提：P1-1 门禁在 0.8B 上通过；
- 4B（NF4，8GB 卡可训但慢）或直接上 **升腾 910B 32GB**（200h 额度）；
- 升腾的用途排序：(a) 4B/更大规模的 ProsQA 训练（本地 8GB 受限）；
  (b) NPU 移植验证（`npu_port_passed:false` 的关账项）；(c) 大样本
  评测加速；
- **不用于**：0.8B 上的任何实验（本地够用）。

## 5. 成功/失败判据（预注册，防事后解释）

| 结果 | 判定 | 论文叙事 |
|---|---|---|
| G1 过 + 自适应点配平 + 圈数省 ≥30% | 命题 A 成立 | "自适应深度退出在规划型任务上以 X% 圈数节省保持满深度质量" |
| G1 过 + 自适应点掉点 >2pp | 退出策略待训（§9 三道门问题重现） | 如实报策略损耗 |
| G1 不过（Δdepth <10pp） | 0.8B retrofit 无深度收益 | 负结果 + 转命题 B/4B |
| ProsQA 上 CoT 基线本身近满 | 任务太简单，换更难任务 | 重选任务（如增大 DAG 深度） |

## 7. 与既有结论的关系（不推翻，只重新框定）

- E0–E3、T-2~T-8 的全部实测数据**保留**：EOS 修复、精确缓存、kernel
  提速都是真资产；
- §28 的"1.49×"降级为**过程记录**（在深度无收益任务上的成本比，无
  结论效力）；
- §29 的对等口径实验（T-9/T-10）结论不变：0.8B 无长链区、d*=1 零触发；
- 本计划只改变**命题、指标、训练数据**三件事。
