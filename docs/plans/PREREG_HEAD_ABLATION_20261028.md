## 一、假设

**H-026（待验证）**：决策模块的形态（容量/打分函数/可见范围）是 hop6 收敛的
瓶颈之一——现有 193 参数的线性头"只读候选自己的隐状态"，逼着 core 把全部
答案压进候选位；给它更强的读出能力可提高 hop6。

**备择（H-026 的反面）**：决策模块不承重，hop6 失败源于 core 的轮次状态本身。
若消融全平，则说明"轻量决策模块足够"，应写进论文作为正面结论。
