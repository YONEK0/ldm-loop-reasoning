## 1. 阶段 1 细目（验证期）

### 任务 A：LDM 轮间瓶颈矩阵【运行中】
- 配置：MVT-3 / 薄core(1) / D8 / round-in-core / 12k 步；瓶颈宽度 {64,16,4,1} × 过程监督 {on,off}；终评 r∈{1,2,4,6,8} × {dev, confirm_depth}。
- 判据（§16.1 预注册，不得改）：通过=任一配置外推 ≥0.60 且随 r 单调升 + dev ≥0.90；部分通过=dev 随 r 显著升但外推 <0.60；失败=轮次贡献全 ≤3pp。
- 产物：`results/bneck_{64,16,4,1}_{sup,nosup}.json`（服务器 → 取回本地 → 归档 §17）。

### 任务 B：4B 文本通道自适应分析【已完成 ✅】
- 结果（n=150，逐轮 sidecar 离线模拟）：

| 策略 | 精度 | 算力 vs 固定r8 | 质量差 |
|---|---:|---:|---:|
| oracle（最早答对轮） | 32.7% | 省 18.0% | +8.7pp |
| 保守 1-or-8 | 28.0% | 省 13.2% | +4.0pp |
| 中档 1-4-8 | 30.7% | 省 16.6% | +6.7pp |
| **可实现：答案稳定性停** | **26.0%** | **省 9.0%** | **+2.0pp** |

- 判定：通过（省 ≥5% 且质量差 ≥0）。**文本通道自适应成立且是当前唯一兑现的省算力形态**；注意所有策略精度都高于固定 r8（固定 8 轮存在"过度思考翻转"损耗，自适应停还避开它）。
- 产物：`results/text_adaptive_analysis.json`（本机+服务器双份）。

## 3. 阶段 2 细目（重训期，待授权）

### 2A 缩尺 loop-native 重训（仅当 D1 通过）
- 对象：0.5B 或 1.5B（Qwen 同族底座结构但**从头训练**或深度续训，配方带瓶颈）
- 训练内容：动态深度（Poisson/均匀）+ 瓶颈轮间传递 + 过程/游标监督 + λ 退火自适应退出（沿用 s67 框架放大）
- 关键落项（映射原始 goal）：面板实时指标（复用 s44 式）、常规存档点（每 N 步）、**永久存档点**（grokking 跃迁/首次外推开锁等转折处，手动+自动双触发）、随机应变暂停准则
- 预算：3080 20G 包日起步，1–3 天量级；里程碑见 §3.3
- 判据（占位，跑前正式预注册）：缩尺上 Fan 签名复现 + 退出控制器难度-轮数分层显现

### 2B 文本通道主线（与 2A 独立，可并行）
- 在线自适应长度生成：置信度/答案稳定性停的实现版（生成侧逐轮判断，非离线模拟）
- 4B 验证协议：同 150 题在线策略 vs 固定 r1/r8 的配对比较；预算 = 推理几小时
- 与 2A 的关系：独立证据链；若 2A 也成立，论文叙事="结构强制串行"在两个维度的实现

### 3.3 里程碑与永久存档点定义（重训期适用）
| 里程碑 | 触发 | 动作 |
|---|---|---|
| M1 训练稳定 | loss 平滑下降 5k 步 | 常规存档 |
| M2 首次外推信号 | confirm 首次 >0.55 | **永久存档点** + 记录配方 |
| M3 Fan 签名 | 外推随 r 单调升 ≥10pp | **永久存档点** |
| M4 退出生效 | 退出分层（难度-轮数相关） | **永久存档点** |
| 异常 | loss 发散/NaN/平台 >20k 步 | 暂停 → 诊断 → 归档后处理 |
