# 0.8B 循环深度：后训练、优化与优势/劣势区间测算

> 版本：V5，2026-10-17，与质量追平优先训练计划同步。
> 状态：主训练与 S3 历史实验完成；质量追平新路线已准备，执行暂停，不启动占卡。
> 执行主计划：`TRAINING_PLAN_V7_0P8B.md` V5；遇到冲突以质量门和正确性门为准。

## 1. 目标与受控对照

阶段一在 Qwen3.5-0.8B-Base 上实现循环深度后训练并优化推理；阶段二测量在什么条件下质量、计算成本、参数利用和内存存在收益或代价。全部主实验基于 0.8B，不擅自添加 2B/4B 对照。

A 是非循环模型后训练，B 是同一原始权重改造后的循环模型后训练。两臂锁定同训练数据、顺序、有效 token 预算、LoRA 层段/配置、有效 batch、优化调度和评测协议。B 新增门/路由和辅助目标另记，因此对照的是整个循环方法；不能声称除了循环次数外没有其他变量。

训练前测原始模型和循环初始化模型；训练后测 A、B-d1、多固定深度、自适应与优化版 B-opt。**B-d1 不自动等于原始模型或训练后的 A。** 原始单遍等价检查需严格旁路 gate/router、保持权重与 masks/positions/norm/head 一致。

主预算按有效 token 配平，不按 FLOPs 配平；每臂实际训练 FLOPs、卡时和参数数都报告。B-opt 如有追加训练，单列预算；配平继续训练的 A 或明确该优化分支不是主同预算对照。

## 2. 数据和评价纪律

- GSM8K train 固定划出训练、验证、退出校准部分，保存 ID、种子、哈希；两臂使用同一切分。
- 验证数据用于早停、配方/深度选择和转折点判断；校准数据用于退出阈值与损失容忍度。
- GSM8K test（1319 题）保留作锁定方案的正式终测，**禁止用 test 子样作过拟合哨兵或调参数据**。
- 通用能力监控使用 wikitext validation；锁定方案后在 test 报 PPL。分词、滑窗、packing 和截断协议固定。
- 所有主对比同条件自测；公开榜单只作注明不同协议的背景信息，不能与我方实测直接计算提升。
- 开发数据上的方向性结论与正式 test 结论分开。准确率用配对差异/置信区间，延迟用重复测量分布；不能用一次均值或几题结果证明收益。

## 3. 质量追平优先与算力兑现顺序（V5）

当前结果把工作拆成三个不能混为一谈的门：

1. **退出可训**：router 能产生多档退出并降低平均深度；0.8B S3 已达到，但不代表质量通过。
2. **质量追平**：adaptive CE 与最优固定深度差值 <= +0.005，strict/完成率不降；这是下一阶段训练目标。
3. **真实加速**：质量通过后才允许跳过 M block、稀疏推进 GDN 状态和测 cache/墙钟。未通过质量门时，只报告退出分布和理论层数。

S3 两轮旧结果（adaptive CE 比 fixed d2 高 +0.049/+0.036）保留为失败但有价值的训练对照。代码审计指出旧路径的 hidden detach、最后监督圈覆盖和硬阈值阻断了质量梯度；后续必须使用可微 continuation probability，并先进行 quality warm-up，再加入 ponder 压力。

### 3.1 质量追平实验

- Q1：只训练 router，冻结 arm B LoRA/L1Gate/backbone；先做单 batch 梯度非零检查。
- Q2：Q1 不过时开放 M 块 LoRA 小学习率；E/D 继续冻结。
- Q3：Q2 不过时再考虑 M 块更大 LoRA或全参；每一级独立预算和归档。
- 固定 d2 teacher、d4 消融、验证/校准切分、test 隔离。每级报告 adaptive CE gap、teacher KL、strict、完成率、重复率、退出直方图和 ponder。

### 3.2 真实加速实验

只有质量门通过后，才进入 exit-skip：必须定义全注意力 KV、GDN conv state、GDN recurrent state 的缺失状态处理，并用 exact full-cache 做教师强制和自由生成对照。随后才测试 cache 预分配、共享/量化 KV、FlashLoop 式惰性更新和 continuous depth-wise batching。

## 4. 缓存优化范围

完整缓存是必备基线：E/D 各一份历史；M 按 `(depth, layer)` 独立保存全注意力 KV 与 GDN 的卷积窗口/递归矩阵/初始化标志。先评估官方 cache 包装适配，旧 s12 的失败不能证明必须弃用官方接口。

G1 比较同权重同语义无缓存参考与完整缓存：完整 prefill、单 token decode、全位置 logits、CE、逐层状态、边界和请求清空。数值容差按精度和 backend 校准后预先锁定；不强制使用未经验证的 bf16 1e-3。容量按实际形状统计，不预设几十 MB。

优化分支如下：

| 分支 | 内容 | 验证要求 |
|---|---|---|
| 完整缓存 | 固定深度；全循环软衰减参考 | G1；权重共享但历史隔离 |
| 保持语义的工程优化 | 预分配/分块缓存、减少历史复制、适配可用融合算子 | G1 复核；两臂同等级优化 |
| 真正早退 | 跳过 M 计算并定义所有缺失历史 | G2；不能仅广播退出 hidden/KV |
| 部署适配 B-opt | 多深度监督、部署语义训练或蒸馏候选 | 单列额外预算，G2'；不保证半 epoch 修复 |
| 跨深度 KV 共享 | first/last 共享分开消融 | 全注意力部分；长生成质量验证 |
| KV 量化 | 参考 KIVI，测压缩和解量化成本 | 不等于 GDN 状态压缩，也不保证加速 |
| GDN 状态优化 | 若做共享/压缩/近似推进，另立实验 | 检查 conv/recurrent 双状态与因果性 |

G2/G2' 同时测同前缀 CE/logits 和自由生成质量、重复/完成率，在独立开发/校准集选阈值。补缓存和补 GDN 状态的计算开销一并计入。未通过时保留完整缓存为默认，并报告已测近似结果，不能称为无损加速。

## 5. 区间测算矩阵

区间边界由数据确定。候选扫描轴为深度 1/2/4/8、自适应阈值、上下文长度、生成长度、batch 和题型。执行前按预算锁定网格，不把 4B 的平均 4.84 圈或 2.4 倍成本迁移为 0.8B 常量。

| 维度 | 对照/测量 | 结论边界 |
|---|---|---|
| 后训练收益 | A/B 同 token 节点质量，终值与提升量 | 测循环方法是否让同数据后训练受益 |
| 深度价值 | B-d1 与 B 多深度，另标 A | 有益、饱和、退化区间；不要求单调 |
| 自适应节省 | B 固定深度完整缓存 vs B 早退 | 相同质量约束下报 FLOPs、墙钟、补状态成本 |
| 相对非循环成本 | A vs B，固定工作量与整题分别计时 | 相同输入/输出工作量下额外循环通常增加算术工作；整题输出长度变化与实现可改变端到端结果，不预设全区间劣势 |
| 缓存收益 | 两臂各测 on/off | 普通缓存收益不能算循环特有收益 |
| 参数利用 | A/B 总参数、可训练参数、新增参数与质量 | 同规模下的参数利用证据；不等于参数缩减率或普遍参数效率定律 |
| 显存与带宽 | 权重、KV、GDN、工作区分别统计，完整/共享/量化对照 | 缓存压缩率不等于模型总显存降幅或 FLOPs 降幅 |
| 任务/长度/batch | 同网格配对测量 | 报收益的条件、质量损失及适用硬件 |

理论层调用代理可按 `E+M×depth+D` 计算，但 GDN/全注意力层成本不同，FFN/输出头/补状态/路由开销也要计入。不能将代理值冒充 profiler 实测或墙钟比例。记录 profiler 对不支持算子的缺项和补充估算。

计时报告 TTFT、逐 token 延迟分布、整题完成时间、实际输出长度和吞吐；NPU 计时前后同步设备并预热，固定 batch/长度性能集与自由生成任务集分开。必要时报告能耗，但必须有测量来源。
